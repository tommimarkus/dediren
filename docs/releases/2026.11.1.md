# Dediren 2026.11.1

Builds the release on a Java runtime patched for
[Java4Shell (CVE-2026-114938)](https://access.redhat.com/security/vulnerabilities/RHSB-2026-018)
and picks up the pending dependency updates.

The CI, CodeQL, release, and render-paint workflows now build on the latest
Eclipse Temurin 25 (`check-latest`), so this archive is produced by a JDK that
carries the upstream fix; it first shipped in Temurin 25.0.5.1 and 21.0.13.1 on
18 November 2026. The bundle still targets Java 21 bytecode and still runs on
Java 21 or newer. The `-XX:-UseBASE64Intrinsics` launcher mitigation from
2026.11.0 stays in place. Dediren does not bundle Java: update your own runtime
to a patched vendor build and restart running processes.

The distribution build now works on JDKs that ship without a `jmods` directory
(Temurin 24 and newer); earlier it failed there in the bundle shrink step.

Runtime dependency updates: Jackson 3.3.0, json-schema-validator 3.0.9, and
Guava 33.8.0. The build moves to Maven 3.10.1.

No JSON schema or command changes.
