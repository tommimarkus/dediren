# Dediren 2026.11.0

Adds a JVM startup mitigation for
[Java4Shell (CVE-2026-114938)](https://access.redhat.com/security/vulnerabilities/RHSB-2026-018),
disclosed on 17 November 2026. The packaged CLI/MCP launcher, Maven host, and
forked test JVMs disable Base64 intrinsics with `-XX:-UseBASE64Intrinsics`.
This makes the mitigation independent of the existing C1-only compilation
setting. The distribution smoke gate checks that the launcher carries it, and
regression tests inspect effective JVM settings.

Compressed draw.io imports decode input-supplied Base64 and can reach the
affected JVM operation. Update to a vendor-patched Java runtime and restart
running processes. Dediren does not bundle or update Java itself. Older bundles
can receive the mitigation through `JAVA_OPTS=-XX:-UseBASE64Intrinsics` at
startup; direct `java` invocations and embedded library use must supply the
option themselves until patched.

No JSON schema or command changes. See the
[threat model](../threat-model.md#java-runtime-and-base64-decoding) for the
mitigation's scope and an effective-launcher verification command.
